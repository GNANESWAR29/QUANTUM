# Quantum AI Stock Trend Prediction System

> **Course Project** | Quantum Computing | Qiskit

Predicts next-day trend (UP / DOWN / NEUTRAL) for 15 NSE stocks using a  
**Variational Quantum Classifier (VQC)** and a **Quantum Kernel SVM**, benchmarked against classical models.

---

## Architecture

`
Raw OHLCV + Sentiment + Analyst data (49,890 rows, 15 stocks, 2014-2026)
        |
        v
Feature Engineering (12 features: returns, volatility, SMA gaps, sentiment, regime)
        |
   ANOVA F-test (train window only) --> 4 features (one per qubit)
        |
   z-score normalisation --> clip +/-3sigma --> angle in [-pi/2, pi/2]
        |
    +---+----+----------------------+
    |        |                      |
    v        v                      v
  VQC   Quantum Kernel SVM    Classical Baselines
 (4q)    (fidelity kernel)    (LR, SVM, GBM)
    |        |                      |
    +--------+----------------------+
                    |
             Prediction: P(UP)
             UP > 0.55 | DOWN < 0.45 | NEUTRAL otherwise
`

### Quantum Circuit (4 qubits, 20 trainable parameters)
- **Feature map (2 reps):** H -> P(2x_i) -> ZZ-entanglers (CX.P(2x_i.x_j).CX)
- **Ansatz (2 layers):** RY.RZ per qubit + CX chain; final RY layer
- **Optimiser:** COBYLA (gradient-free, handles shot noise well)
- **Readout:** <Z0> = 1 - 2*P(qubit_0=|1>) --> sigmoid(a*<Z0> + b) = P(UP)

## Quick Start

### 1. Install dependencies

`ash
pip install -r requirements.txt
`

### 2. Verify Qiskit backend (optional)

`ash
python verify_backends.py
`
Expected output: max |qiskit - numpy| ~ 1e-16

### 3. Train with NumPy backend (fast, ~30 seconds)

`ash
python train.py
`

### 4. Train with Qiskit backend (slow, uses Qiskit Statevector)

`ash
python train.py --backend qiskit --n-train 200 --n-test 300 --maxiter 100
`

### 5. Open the demo website

`ash
# Option A: just open the file
start website/index.html

# Option B: serve it locally
cd website && python -m http.server 8080

## Results (held-out 2023-2026)

| Model | Accuracy | AUC | Notes |
|-------|----------|-----|-------|
| Majority class | 50.3% | 0.500 | Baseline |
| Logistic regression | 50.9% | 0.515 | 4 features |
| Classical RBF-SVM | 49.2% | 0.504 | 4 features |
| **Gradient Boosting** | **54.4%** | **0.549** | **12 features, best** |
| Quantum Kernel SVM | 50.4% | 0.505 | 4 qubits |
| VQC | 50.0% | 0.492 | 4 qubits, 20 params |

### Honest interpretation
- All models score near 50% accuracy / 0.5 AUC -- no model shows reliable edge
- This is the **expected and correct** result, not a failure:
  - Market efficiency: most public signals are already priced in
  - 4 qubits can only encode 4 features -- severely limits expressivity
  - Simulated NISQ circuits with no error mitigation perform like random classifiers
  - COBYLA converges to a flat loss near ln(2) ~0.693 (barren plateau)
- Gradient Boosting on 12 features reaches 54.4% -- still not statistically significant

## Known Limitations & Future Work
- Scale to 8+ qubits with hardware-efficient ansatz (only possible on real QPU)
- Apply zero-noise extrapolation (ZNE) for hardware runs
- Use QAOA for portfolio selection (QUBO formulation)
- Distill the quantum model into a classical surrogate for low-latency inference
- Extend to multi-class (UP/DOWN/NEUTRAL) with softmax readout
- Explore Quantum Amplitude Estimation for faster Monte Carlo VaR
